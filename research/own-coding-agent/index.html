Why I stopped building my own coding agent

Written from the research log on this site; no new findings. Problem, starting assumption, experiment, results, limitations, decision.

Problem

When the first coding CLIs came out, the potential was obvious, and so was the fact that they weren’t there yet.

Starting assumption

An agent of my own, built from scratch, might close that gap.

Experiment

First an own agent, built from scratch. Then, in June 2026, a coding runtime on the server: change plan, isolated workspace, validation, commit, pull request, tried in a local test run.

Results

The CLIs overtook my own agent fast. The server runtime showed many expensive model turns, few real actions and success claims without enough evidence.

Limitations

Before the first commit of Octryx AI there are no exact dates, and the research log does not publish figures for these runs. This is a record of what I saw, not a benchmark.

Decision

Octryx AI runs an existing coding agent instead of being one (September 2026): Claude Code on the developer’s machine, with Octryx AI in between to steer, audit and enforce. Since v0.0.2-alpha, Codex runs next to Claude Code, on developer machines and on server runners.
