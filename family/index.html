THE OCTRYX FAMILY

Four open-source projects, one idea: understand what happens.

Octryx is a family of four projects. Each one started where the one before it hit its limit. All four are alpha, all four will be published under Apache 2.0, and I work on all four at the same time.

Octryx AI

Alpha
The layer above your coding agents.

One process, one set of rules and one record for the whole team, from an idea in chat to a reviewed pull request. Something researched once is available to everyone.

Started
After the first AI command-line tools; part of my bachelor’s thesis
Licence
Apache 2.0, public on GitHub

Capisco

Alpha
A UI builder. Italian for “I understand”.

Build any application on your own data: pages, data integration and workflows you define directly, so you always understand what happens and how it works. It helps people who don’t need an AI directly, but could do more with one.

Started
Spring 2024
Licence
Apache 2.0, public after a clean-up

Decyra

Alpha
Decisions based on data.

Connects different sources and lets you transform data and decide on it: a backend that is easy to extend and easy to understand. Started in Java, now Rust and Python, because simpler is often better.

Started
Late 2023, as a project during my studies
Licence
Apache 2.0, public after a clean-up

Data Platform

Alpha
A complete stack for your own data.

From the data warehouse to ML experiments, with a UI on top of well-known open-source components. Mostly infrastructure: everyone should be able to run a data platform, understand their data and work data-driven.

Started
Early 2024
Licence
Apache 2.0, public after a clean-up
HOW THEY CONNECT

Each project closes the gap the last one left.

  1. 01 · late 2023DecyraA study project for six months. The result was a proof of concept, not something anyone could use. It taught me ML models and inference, and pushed me to data platforms.
  2. 02 · early 2024Data PlatformNothing simple existed to run your own data. Each solution grew more complex. The result was judged poorly anyway: there was no UI.
  3. 03 · spring 2024CapiscoWho uses the result in the end? Instead of one fixed UI, a way to build the UI yourself, together with data and workflows.
  4. 04 · with the AI toolsOctryx AIFrom copying code out of a web chat to the first command-line agents and their mistakes: a team needs process, checks and shared knowledge around them.

The whole story, with what worked and what didn’t: Research.

WHY FOUR AT ONCE

I switch between them on purpose.

Many ideas come to me, and working on only one thing at 100% is hard. So I allow myself to switch between the four projects. That keeps all of them interesting for the long run.

Now the time has come for everyone to use them and to take part.

— Luca Campisi, founder
