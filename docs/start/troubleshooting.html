Troubleshooting ​

Common problems and their fixes. If yours is not here, see Report a bug.

Installing with Docker Compose ​

Message or signCause and fix
required variable LLM_PROVIDER is missing.env is missing or no model block is filled in. See Docker Compose.
startup.llm_provider_unsupported in the logLLM_PROVIDER takes anthropic, openai, bedrock or openrouter. Add other providers later in Admin › Models.
port is already allocatedPort 8000 is taken. Set OCTRYX_PORT=8080 in .env.
No "setup code" in the logThe api is still starting: docker compose logs -f api.
Sign-in returns to the login page without an errorThe browser drops secure cookies on plain http. Use localhost, not the IP address.
Chat: authentication_error or an invalid keyThe model key is wrong or revoked. Fix it under Admin › Models.
Bedrock: ExpiredToken or AccessDeniedThe AWS keys expired. Export them again, then docker compose up -d.
Chat: model not foundThe model is not available to your key or region. Change AGENT_DEFAULT_MODEL or AWS_REGION.
Changing .env has no effect.env is read on the first start only. Change model access under Admin › Models.
"has no price – costs are not counted"A notice only. Add the price under Admin › Models › Catalog.

Installing on Kubernetes ​

Message or signCause and fix
existingSecret is required, host is requiredThe value is missing in your values file.
Pod or volume PendingNo default StorageClass. Set persistence.storageClass.
The migrate init container keeps restartingThe database is unreachable, or the password does not match. Check its log.
Large uploads break offThe ingress body limit is too small.
Knowledge says needs_configurationSet the object store's endpoint and bucket. See Knowledge storage.

The launcher ​

SignCause and fix
Seat "not logged in" or "login expired"Run octryx-claude login --seat again.
Seat "limit reached"Your subscription's limit. A running run goes on with a company model of the same class and returns to the seat after the reset (Seats); if the Workspace admits none, it pauses until then. Work held on the agent board is handed over to a colleague instead.
needs_configuration: no Claude model admitted and seat not allowedThe Workspace allows no Claude model and no seat. Ask a Workspace admin.
seat_session_expiredA seat session is valid for 12 hours. Start a new session.
Sign-in renewal failsRun octryx-claude login again.
The installer says Python has no venvInstall python3-venv (Debian, Ubuntu).
native_windows_unsupportedNative Windows is not supported. Use WSL2.
Claude Code exits at start because its sandbox is unavailableThe launcher requires Claude Code's sandbox. Install what your system needs for it; see Claude Code's documentation.
A self-update failedOnly a warning; the old version keeps working. A failed version is retried after an hour; one that never comes up healthy is rolled back and blocked for 24 hours. OCTRYX_CLAUDE_AUTO_UPDATE=0 turns updates off.
A run card shows Follow-up not started, or a run is refused with "No device yet"The triage is done, but its follow-up workflow builds and tests code, and that runs only on a paired machine. Follow Pair Claude Code with the launcher (Agents › Install octryx-claude), enable a device folder, then start the workflow again. See First run.
device_folder_not_accessible when adding a folder or before a jobThe device service cannot read the folder, for example macOS Desktop or Documents. Use another folder, or give the service access. device status shows each folder's access.

In the app ​

SignCause and fix
Search says "Choose a workspace"Pick a Workspace with the icon at the top of the left bar.
An MCP server's tools do not appearA server does nothing until it is allowed in the Workspace. See MCP servers.
A connection shows FailingOpen it, then Test for the reason. See Connections.
A run pauses with "Nothing was counted against the agent"The platform could not attribute a test result; see Evidence and checks.
