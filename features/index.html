Words we use
Workspace
One team’s space: its own rules, knowledge, models and costs.
Run
One piece of work from start to pull request, step by step, with a full record.
Seat
A person’s own Claude or ChatGPT subscription, used through Octryx AI.
Device job
Work that runs on a developer’s machine instead of the server.
Data class
How sensitive data is, from Public to Secret; it decides which models may see it.
Shadow mode
A rule is checked and logged, but does not block yet.
